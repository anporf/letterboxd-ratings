# Letterboxd List Ratings

Браузерное расширение (Manifest V3), которое показывает твои оценки и лайки прямо на постерах фильмов в списках Letterboxd.

![Пример работы расширения](https://i.imgur.com/placeholder.png)

## Как выглядит

На каждом постере в списке появляется бейдж с:
- ⭐ звёздами (например `★★★★½`)
- ❤ если фильм лайкнут

## Установка (локально)

1. Клонируй или скачай репозиторий
2. Открой `яндекс://extensions` (или `chrome://extensions`)
3. Включи **Режим разработчика** (Developer mode)
4. Нажми **Загрузить распакованное** → выбери папку с расширением
5. Нажми на иконку расширения → введи свой Letterboxd username → **Сохранить**
6. Открой любой список, например `https://letterboxd.com/username/list/listname/`

## Как это работает

```
Ввод username
     ↓
chrome.storage.local  ←──────────────────────────────────┐
     ↓                                                    │
Fetch /username/films/ratings/ (все страницы, до 25)     │
Fetch /username/likes/films/   (все страницы, до 25)     │
     ↓                                                    │
Строим Map: { "film-slug": { rating: 4.5, liked: true } }│
     ↓                                                    │
Сохраняем в кэш (TTL 24 часа) ───────────────────────────┘
     ↓
Ждём загрузки React-постеров на странице (MutationObserver)
     ↓
Для каждого [data-item-slug] ищем slug в Map → рисуем бейдж
```

### Хранение данных

| Что | Где | Когда удаляется |
|-----|-----|-----------------|
| Username | `chrome.storage.local` | При удалении расширения |
| Кэш рейтингов | `chrome.storage.local` | Через 24 часа или кнопкой «Очистить кэш» |

Данные хранятся **локально в браузере** и никуда не отправляются.

### Почему нужен username

Letterboxd не предоставляет API для авторизации в расширениях. Расширение делает обычный `fetch` на публичные страницы профиля (ratings, likes) от имени залогиненного пользователя — браузер автоматически подставляет cookies сессии (`credentials: 'include'`).

## Файлы

```
letterboxd-ratings/
├── manifest.json   — конфигурация расширения (MV3)
├── content.js      — инжектируется на страницы списков
├── popup.html      — интерфейс попапа
├── popup.js        — логика попапа (сохранение username, очистка кэша)
└── styles.css      — стили бейджей
```

## Поддерживаемые страницы

- `https://letterboxd.com/*/list/*` — пользовательские списки

## Разработка

Редактируй файлы → в `яндекс://extensions` нажимай ↺ (обновить) на карточке расширения → обновляй страницу Letterboxd.

После изменений в `content.js` или `manifest.json` обязательно перезагружай расширение через ↺.
