# Letterboxd List Ratings

Браузерное расширение (Manifest V3), которое показывает твои оценки и лайки прямо на постерах фильмов в списках Letterboxd — без ручного ввода username.

## Как выглядит

На каждом постере в списке появляется бейдж с:
- ⭐ звёздами (например `★★★★½`)
- ❤ если фильм лайкнут

## Установка (локально)

1. Клонируй или скачай репозиторий
2. Открой `яндекс://extensions` (или `chrome://extensions`)
3. Включи **Режим разработчика** (Developer mode)
4. Нажми **Загрузить распакованное** → выбери папку с расширением
5. Войди в свой аккаунт на letterboxd.com
6. Открой любой список, например `https://letterboxd.com/username/list/listname/`
7. Бейджи появятся автоматически

## Как это работает

**Рейтинги** — Letterboxd встраивает оценку залогиненного пользователя прямо в HTML страницы списка в атрибут `data-owner-rating` на `li.posteritem`. Расширение читает их из DOM напрямую — никаких запросов не нужно.

**Лайки** — Letterboxd не встраивает состояние лайков в HTML списка заранее (загружает лениво при ховере). Расширение автоматически определяет username из DOM и делает один быстрый fetch страниц лайков (`/username/likes/films/`). Результат кэшируется на 24 часа.

```
Открываешь список на letterboxd.com (залогинен)
     ↓
content.js ждёт рендера React-постеров (MutationObserver)
     ↓
Рейтинги: читает data-owner-rating из li.posteritem → рисует ★
     ↓
Лайки: определяет username из DOM → fetch /username/likes/films/
       → кэш в chrome.storage.local (TTL 24ч) → рисует ❤
```

## Попап расширения

- **Скрыть / Показать оценки** — переключить видимость бейджей
- **Очистить кэш лайков** — сбросить кэш, при следующей загрузке лайки скачаются заново

## Файлы

```
letterboxd-ratings/
├── manifest.json   — конфигурация расширения (MV3)
├── content.js      — инжектируется на страницы списков, рисует бейджи
├── popup.html      — интерфейс попапа
├── popup.js        — toggle и очистка кэша
└── styles.css      — стили бейджей
```

## Поддерживаемые страницы

- `https://letterboxd.com/*/list/*` — пользовательские списки

> Нужна поддержка `/watchlist/` или других разделов? Добавь паттерн в `matches` в `manifest.json`.

## Разработка

Редактируй файлы → в `яндекс://extensions` нажимай ↺ на карточке расширения → обновляй страницу Letterboxd.
