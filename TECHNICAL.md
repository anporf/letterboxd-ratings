# Техническая документация

## Как это работает

**Рейтинги** — Letterboxd встраивает оценку залогиненного пользователя прямо в HTML страницы списка в атрибут `data-owner-rating` на `li.posteritem`. Расширение читает их из DOM напрямую — никаких запросов не нужно.

**Лайки** (ветка `with-likes`) — Letterboxd не встраивает состояние лайков в HTML списка заранее (загружает лениво при ховере). Расширение автоматически определяет username из DOM и делает fetch страниц лайков (`/username/likes/films/`). Результат кэшируется на 24 часа.

```
Открываешь список на letterboxd.com (залогинен)
     ↓
content.js ждёт рендера React-постеров (MutationObserver)
     ↓
Рейтинги: читает data-owner-rating из li.posteritem → рисует ★
```

## Файлы

```
letterboxd-ratings/
├── manifest.json   — конфигурация расширения (MV3)
├── content.js      — инжектируется на страницы списков, рисует бейджи
├── popup.html      — интерфейс попапа
├── popup.js        — toggle видимости бейджей
├── styles.css      — стили бейджей
└── TECHNICAL.md    — этот файл
```

## Разрешения

| Разрешение | Зачем |
|---|---|
| `tabs` | Отправить сообщение в активную вкладку из попапа |
| `activeTab` | Доступ к текущей вкладке |
| `https://letterboxd.com/*` | `host_permissions` для content script и fetch |

## Поддерживаемые страницы

- `https://letterboxd.com/*/list/*` — пользовательские списки

Чтобы добавить поддержку других страниц (watchlist, diary и т.д.), добавь паттерн в `matches` в `manifest.json`.

## Ветки

| Ветка | Описание |
|---|---|
| `main` | Только оценки — читает из DOM, без запросов |
| `with-likes` | Оценки + лайки — автоопределение username, fetch с кэшом 24ч |

## Разработка

Редактируй файлы → в `яндекс://extensions` или `chrome://extensions` нажимай ↺ на карточке расширения → обновляй страницу Letterboxd.
